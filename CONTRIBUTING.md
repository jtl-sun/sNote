# Contributing

1. Create a branch from `main`.
2. Create a virtual environment and install `pip install -e .[dev]`.
3. Run `ruff check .` and `pytest`.
4. Keep personal notes, recent-file lists, and machine-specific paths out of commits.
5. Open a pull request describing the user-visible behavior and verification performed.

Please keep changes focused. New shortcuts should not conflict with the shortcuts listed in the
README, and file operations should preserve user data when an operation fails.
